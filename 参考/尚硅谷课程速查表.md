### 阶段 2 用它替代原计划的 B 站数据分析课

`video/339` 的目录比原计划那门更对口：

| 节号 | 内容 | 正好对上你计划的哪一天 |
|---|---|---|
| 02–05 | Anaconda 安装、**Jupyter 使用**、PyCharm 里用 Jupyter | D031 |
| 06–21 | **NumPy 全套**（ndarray 特性/属性/创建/数据类型/索引切片/运算/数学函数/**统计函数**/比较/排序 + 2 个练习） | D032–D037 |
| 22–41 | Pandas Series / DataFrame（含 5 个案例） | D038–D041 |
| 42–52 | 数据导入导出、缺失值、类型转换、数据变形、分箱、**时间数据**、**分组聚合** | D042–D043 |
| 53–61 | Matplotlib 折线/条形/饼/散点/**箱线图**、多图绘制、**Seaborn** | D039–D040 |
| 62–69 | 项目实战：房价数据分析完整流程 | D044 |

> ⚠️ 官网目录里**没有单列「广播 broadcasting」**这一节，而这是 NumPy 最关键的概念。
> D034 那天仍然按计划自己补（B 站搜「NumPy 广播 10 分钟」）。

### 阶段 3 用它替代刘二大人 + 李沐

`video/348` 的结构**特别契合你的计划里「先手推再调库」的要求**：

| 节号 | 内容 |
|---|---|
| 001–041 | 神经网络原理 + 手写数字识别，**全部手工实现，不用框架**（含数值微分、梯度计算、手写反向传播的链式法则推导） |
| 042–055 | 深度网络技巧：梯度消失/爆炸、动量、AdaGrad、RMSProp、Adam、Xavier/He 初始化、BatchNorm、Dropout |
| 056–086 | **PyTorch 上手**：安装与 CUDA 验证、张量创建/转换/运算/索引/形状操作、自动微分（含 detach）、线性回归 |
| 087–111 | PyTorch 搭网络：激活函数、全连接、Dropout、Sequential、损失函数、优化器、**房价预测案例** |
| 112–126 | **CNN**：卷积运算、填充、步幅、池化、服装分类（Fashion-MNIST）案例 |
| 127–138 | NLP 入门：词向量、嵌入层、RNN、古诗生成案例 |

**注意两点**：
1. 官方说明「PyTorch 深度学习是机器学习的后续课程」，前置知识写的是「数学基础 + 熟练掌握 Python + 机器学习基本概念」。**所以你可能会在 001–055 感到吃力**——遇到卡住的地方，回头补线性代数和概率的对应部分，或者先跳到 056 学 PyTorch 再回来。
2. 它**没有 CIFAR-10**，是 Fashion-MNIST。计划里的 CIFAR-10 验收任务可以自己找教程补，或者改用 Fashion-MNIST 达成同样目的（都会写 CNN 训练循环）。

## ⚠️ 尚硅谷没有强化学习课

我逐个试了 id 340–358，**没有 RL 课程**。他们的 AI 线终点是 NLP / LangChain / 大模型，不是强化学习。

**所以第四阶段（D092–D103）仍然按原计划走**：
- 蘑菇书 EasyRL（B 站搜「采蘑菇教程 Easy RL」）
- 上交大张伟楠《动手学强化学习》
- CleanRL 源码

## 防止找错课

- B 站上有一堆搬运号把尚硅谷的课重传，标题会改。**认准 UP 主是「尚硅谷」官方号**，或者直接用上面的官网链接。
- 官网页面上的「点击试看」是 JS 按钮，需要在页面里点；「免费下载」同理（可能需要关注公众号/加群）。
- **最省事的方式**：官网下载整套视频 + 源码 + 课件 + 笔记到本地，用播放器看（可倍速、可跳节、不受网络影响）。
