## 二、D001 的完整操作步骤

### Step 1：装 Miniconda（约 15 分钟）

1. 打开 https://docs.conda.com/miniconda/ 或直接搜 "Miniconda 下载"，选 **Windows 64-bit installer**
2. 安装时**务必勾选**：
   - ✅ Add Miniconda3 to my PATH environment variable
   - ✅ Register Miniconda3 as my default Python
3. 装完**关掉所有终端窗口，重开一个**（不重开 PATH 不生效）
4. 验证：
   ```bash
   conda --version
   ```
   能输出版本号就成功。

> 为什么不用 Anaconda：它自带几百个你用不到的包，装完 3GB+，还容易和环境冲突。

### Step 2：创建学习环境（约 3 分钟）

```bash
conda create -n rl python=3.10 -y
conda activate rl
```

看到命令行前面出现 `(rl)` 就成功了。

**记住：以后每次敲代码前，第一件事就是 `conda activate rl`。** 忘了这步是最常见的"为什么我的包明明装了却 import 不到"。

### Step 3：VS Code 装 3 个扩展（约 3 分钟）

打开 VS Code → 左侧方块图标（扩展）→ 搜索并安装：

| 扩展 | 作用 |
|---|---|
| **Python**（Microsoft） | 语法高亮、运行、调试 |
| **Pylance**（Microsoft） | 智能提示、类型检查 |
| **Jupyter**（Microsoft） | 跑 `.ipynb` 笔记文件 |

装完后，`Ctrl+Shift+P` → 输入 `Python: Select Interpreter` → 选 **rl** 那个环境（路径里带 `miniconda3\envs\rl`）。

### Step 4：把仓库用 VS Code 打开

VS Code → 文件 → 打开文件夹 → 选 `D:\code\python-learning`

打开后左侧应该能看到 `00-计划`、`01-Python基础`、`notes` 等文件夹。

### Step 5：写第一行代码（D001 的核心任务）

在 `01-Python基础\week1\` 里新建文件 `D001_hello.py`，内容：

```python
# D001 - 2026-10-03
# 第一行 Python 代码

print("Hello, Python!")
print("我是大工的，104 天后我要手写 PPO")

# 试试基本运算
print(1 + 2)
print(10 / 3)      # 注意：Python 的除法结果是小数
print(10 // 3)     # 整除用两个斜杠
print(2 ** 10)     # 幂运算

# 变量不需要声明类型
name = "小明"
age = 20
print(f"我是{name}，今年{age}岁")   # f-string，最常用的字符串格式化
```

**运行方式（两种都学会）**：
- VS Code 里按 `Ctrl+F5`，或点右上角 ▶ 按钮
- 终端里：`python 01-Python基础/week1/D001_hello.py`

### Step 6：提交（今天的收尾）

## 三、卡住了怎么办

| 症状 | 原因 | 解决 |
|---|---|---|
| `conda : 无法将"conda"项识别为...` | PATH 没生效 | 关掉所有终端重开；还不行就重启电脑 |
| VS Code 里 import numpy 报错 | 解释器选错了 | `Ctrl+Shift+P` → Select Interpreter → 选 rl |
| `python` 命令没反应 | 系统 Python 和 conda Python 冲突 | 先 `conda activate rl` 再跑；或改用 `python3` |
| git commit 报 `Please tell me who you are` | 没配用户名邮箱 | `git config --global user.email "你的邮箱"` 和 `git config --global user.name "你的名字"` |
| 中文乱码 | Windows 默认编码是 GBK | 读写文件时都加 `encoding='utf-8'` |

**任何卡住超过 1 小时的问题，直接问 AI。** 不要一个人闷头卡三天，那是新手最大的浪费。
