## 使用说明（先读这 300 字）

1. **每天分三块，不许合并**：
   - 【看】60–90 分钟，看视频课
   - 【敲】90–120 分钟，**关掉视频，凭记忆重写当天代码**
   - 【记】20–30 分钟，把当天代码+心得写进 `learning-log.ipynb`，`git commit`
2. **每天的验收标准是"能不看视频写出代码"**，不是"看完视频"。做不到就在当天【敲】时段回头补，别拖到明天。
3. **打卡方式**：文件名 `D001`–`D104`。每天一个 commit，commit message 格式：`D012: 函数进阶-闭包与装饰器`。
4. **断签规则**：允许断，不允许"欠账"。断一天就在最近的 ⚪ 缓冲日补，缓冲日不够就砍掉标了 🟡 的选修内容。
5. **🟡 标记 = 可牺牲**。🔴 标记 = 核心，牺牲了整条路线崩。

### 🔴 第一阶段总验收（D030 结束前必须全部满足）

写一个「学生成绩管理系统」，要求：
1. 用**字典**存数据，支持增 / 删 / 改 / 查 / 排序 / 统计
2. 拆成 **至少 2 个模块**（`main.py` + `manager.py`）
3. 数据**持久化到 JSON**，重开程序数据不丢
4. 有**完整的异常处理**（输入非数字、文件不存在都要优雅处理）
5. 用 **`class` 组织**，不许全是散装函数
6. **至少用一处列表推导式**和一处 f-string（检查你有没有真的学会新东西）
