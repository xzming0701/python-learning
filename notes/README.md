# notes - 学习笔记

## learning-log.ipynb

**从 D001 开始，每天往里追加一节。** 这是整个仓库里最值钱的文件。

### 每节的固定格式

```markdown
## D012 · 2026-10-14 · 列表推导式

### 今天学了什么
（3 行以内，用自己的话说，不要抄课件）

### 关键代码
（贴 5-15 行最能说明问题的代码）

### 踩的坑
- 写 `[x*2 for x in a if x>0]` 时把 if 放到了前面，报 SyntaxError
- 记住：筛选条件在 for 后面，变换表达式在最前面

### 还没搞懂的
- 嵌套推导式里两个 for 的执行顺序
```

### 为什么必须写「踩的坑」

因为**你会踩第二次**。三个月后写 PPO 时遇到 shape 报错，翻笔记发现 D034 就踩过一次 —— 这一条能帮你省两小时。

### 为什么必须写「还没搞懂的」

把一个模糊的问题**写成一句话**，本身就会逼你想清楚它卡在哪。而且这些问题是你复习时的第一优先级。
