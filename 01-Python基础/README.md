## 三个 Python 特有的大坑（C 语言没有）

```python
# 坑 1：可变默认参数
def f(x, acc=[]):     # 错！acc 会在多次调用之间累积
    acc.append(x); return acc
def f(x, acc=None):   # 对
    if acc is None: acc = []
    acc.append(x); return acc

# 坑 2：浅拷贝 —— b 和 a 是同一个列表
a = [1, 2, 3]; b = a; b.append(4)   # a 也变成 [1,2,3,4]
b = a.copy()                        # 这样才是复制

# 坑 3：除法
print(7 / 2)    # 3.5（不是 3）
print(7 // 2)   # 3
```
